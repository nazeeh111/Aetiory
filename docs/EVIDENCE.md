# Evidence for 0.1.0

The recorded studio is generated from the released engine's actual automatic
searches and fresh paired replays. It does not run Python in the browser.
[Machine-readable identities and results](evidence.json) retain source and output
hashes. These records check consistency, not author authenticity.

Local defining cases used CPython 3.14.7 on macOS, with unmodified source modules:

| Case | Observed returns | Eligible candidates | Actual paired trials | Selected result |
|---|---:|---:|---:|---|
| `difflib` over two complete released verifier sources | 1,592 | 462 | 81 | Anchored code cell `from0_72`, following element sibling 1 |
| Recursive `pprint` over a 396,108-byte native report | 251,728 | 335 | 11 | `/baseline/outputs/MANIFOLD/faces/98/1`, 56 to 57 |

Both cases passed plain/instrumented byte parity, unchanged paired-parent parity,
actual selected child change, native child reaping, exact fresh unchanged output
and a new intervention replay that independently re-evaluated the selector.
The diff changes two anchored code cells and their containing table. The report
changes one parsed representation leaf. It does not create a new native geometry
measurement or repair the original geometry.

Original and alternate output bytes are embedded in the record and independently
hashed by the browser. The source files and declared inputs remain unchanged.
Argument previews and observed call ancestry are navigation, not complete dataflow.
Large traces and failed/no-effect trial receipts are retained locally; the portable
viewer includes the accepted artifacts and recorded evidence.

## Verification scope

- 30 Python test methods exercise the real native engine, controlled refusals,
  source/input/interpreter drift, event/value/path/prefix guards, imported plan
  semantics and recipe bounds, opaque targets, no-clobber, timeout and interruption
  with actual forked-child cleanup, MCP framing and a real observe/search/replay/export
  journey. Synthetic protocol/resource fixtures are explicitly labelled.
- 47 browser-record contracts and 54 actual controller checks cover hashes,
  incomplete/contradictory records, safe text rendering, malformed import recovery,
  download gating and asynchronous stale-result exclusion. Minimal DOM checks
  do not establish browser layout.
- Fresh independent core review reproduced three real flaws in the earlier engine:
  unchecked replay selectors, unbound descriptive trace metadata and imported
  recipe bounds. The corrected core passed 15 independent controls, a real HTML
  paired experiment and focused timeout/interruption checks.
- Fresh independent MCP review passed 44 contracts after correcting UTF-8 frame
  accounting, initialization, notification responses and serialized output bounds.
  Its stubbed core handoff is separate from the real native journey.
- Fresh export review independently runs a small real generator-bearing program.
  Contradictory receipt flags, selectors and descriptive value/hash metadata must
  refuse, even when retained artifact files still exist.

The actual studio was operated at 1280-pixel desktop and 360-pixel mobile widths.
Its real downloaded 2,227,676-byte record matched the source payload, imported with
an unauthenticated label, and a malformed import preserved the earlier result.
A fresh installed wheel outside the checkout passed an isolated native tool journey and portable export with all six browser resources present. Hosted CI is recorded separately before release.

## Limits

These are bounded examples and tests, not universal correctness, performance,
complete causal proof or an operating-system sandbox. Python execution remains
trusted and local. Portable return prefix guards include opaque type/location
markers, not serialized opaque heap state. Actual live state is copied by process
fork, with synchronous/fork-compatible resources required. External effects are
not rolled back. Mid-call MCP cancellation is unsupported; local process timeouts
and native CLI interruption handle owned workers.

Direct standalone file opening could not be tested in the controlled browser: its URL policy refuses file://. No alternate browser or URL workaround was used. The inline consumer passed a zero-fetch minimal-DOM startup check; regular HTTP studio interaction and record round-trip were verified separately.
